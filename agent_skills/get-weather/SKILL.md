# 获取天气技能 (get_weather)

## 使用场景
当用户询问某个城市的天气情况时使用此技能

## 执行步骤
1. 从用户消息中提取城市名称
2. 使用fetch_url工具访问wttr.in天气服务
    - URL格式：https://wttr.in/[城市名]?format=j1&lang=zh
3. 解析返回的JSON数据，提取关键信息：
    - 当前温度
    - 湿度
    - 风速
4. 用自然语言向用户汇报天气情况

## 示例
- 用户：[查询北京的天气]
- 执行结果：
    1. 提取城市：北京 (Beijing)
    2. 调用fetch_url工具
    3. 解析JSON结果
    4. 回复：[北京当前天气：晴，温度25℃，湿度40%，东风3级。]

## 注意事项
- 城市名建议使用英文格式以提高准确性
